# DDoS Simulation & Mitigation Report

## 1. Objective

To demonstrate controlled DDoS-style HTTP traffic simulation,
detection, and mitigation in an authorized laboratory environment.

## 2. Environment

- OS: Ubuntu
- Web Server: Nginx
- Traffic Tool: curl
- Detection: Nginx access logs
- Mitigation: Nginx rate limiting

## 3. Simulation

Controlled HTTP requests were generated against the authorized
lab server.

## 4. Detection

Nginx access logs were analyzed to identify abnormal request
patterns and high-volume sources.

## 5. Mitigation

Nginx rate limiting was configured to control excessive requests.

## 6. Results

Traffic behavior was compared before and after mitigation.

## 7. Conclusion

The lab demonstrated a basic defensive workflow for detecting
and mitigating abnormal HTTP traffic.

## 8. Disclaimer

Testing was performed only against an authorized laboratory
environment.
